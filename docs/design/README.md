# Roudio — design (Tide Clock direction, October 2026)

Static screen designs for Roudio. The apps are built from these: colours,
radii and type come from the Paper tokens via `packages/design-tokens`.

- **Editable designs:** Paper file **“Roudio — Fresh Direction (Oct 2026)”**
  (https://app.paper.design/file/01M4JN5MF7KH805065DG9T8AD1). The older
  “Roudio” Paper file belongs to the rejected direction and was left
  untouched.
- **Chosen direction:** C, Tide Clock (the day as a 24-hour dial). Other
  directions were removed from the file; see `brand-directions.md`.
- **Image exports:** `exports/tide-clock/` (phone, one PNG per artboard,
  named after the artboard) and `exports/web/` (web version, page “07 Web”).
- **Plain-language brief:** `../roudio-brief.md`.
- `design-decisions.md`: the visual direction and the reasons behind it.
- `screen-inventory.md`: every artboard, which theme it's in, and which
  states it covers.
- `flow-and-states.md`: navigation, Back behaviour, and state coverage per
  screen.
- `implementation-checks.md`: what a static design can't prove, plus the
  open hardware and service questions.

All recordings, people, times and accounts in the designs are **sample data**.
